文章标题：关于现代 Web 界面布局的深度解析

这是第一段占位文字。微软雅黑字体（Microsoft YaHei）在现代浏览器和操作系统中具有极佳的清晰度与可读性，非常适合用于展示长文本内容和文章大纲。

这是第二段占位文字。页面采用了响应式与固定定位结合的设计。左侧表层容器通过 CSS 的 position: fixed 实现了不随屏幕滚动的效果，而其内部如果内容超出了定义的高度（上下 30% 至 70% 之间），则可以通过设置 overflow-y: auto 独立滚动。

这是第三段占位文字。底层容器占据屏幕横向 30% 到 80% 的区域，通过常规的文档流向下延伸。当读者向下滚动页面时，主体文章会顺畅滚动，而左侧的索引导航栏始终固定在窗口的特定位置，方便随时跳转或查阅大纲。

这是第四段占位文字。文字排版在网页设计中至关重要，合理的行高（line-height）、字间距以及段落间距能够极大地提升用户的阅读体验。在浅色背景下选用暗灰色字体，比纯黑色字体更不容易让人感到视觉疲劳。

这是第五段占位文字。你可以继续在此处添加更多的内容。为了演示长页面的滚动效果，这里放置了大量的占位段落。你可以试着用鼠标滚轮向下滑动，观察左侧索引框与中间主体文字的互动方式。

这是第六段占位文字。继续向下阅读，底层容器的最下方准备了两个分页链接“上一页”和“下一页”，用于在多页长图文之间进行切换导航。

这是第七段占位文字。技术的不断演进使得 CSS 布局变得越来越丰富，从传统的浮动布局到弹性盒子（Flexbox），再到网格布局（Grid）以及固定/绝对定位，开发者可以轻松实现各种复杂的叠层与交互界面。
